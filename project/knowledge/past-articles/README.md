# Past articles

Put the writer's previously published blogs here (export from Google Docs as .docx or .md).
Upload them to the claude.ai Project's knowledge together with the other files in `project/knowledge/`.

Tips:
- Name files by topic, e.g. `2025-06-aiops-for-hybrid-cloud.docx`, so overlap checks are easy.
- Pick the 3-5 strongest ones, in the voice she wants to keep, for creating the custom Style (see the main README).
- Leave out this README when uploading.
