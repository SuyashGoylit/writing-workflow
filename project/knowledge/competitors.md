## Notes
- **Cloud4C is part of Capgemini** (acquisition completed in 2025). Capgemini is still on this list, so the Cloud4C pitch must **never** mention Capgemini or the parent company.
- **Red Hat is an IBM subsidiary.** It isn't on the list, but using redhat.com as a source links to an IBM-owned brand. Treat Red Hat as a background-only source unless the writer says otherwise.
- The word "orange" as a colour, or "BT" inside another acronym, is fine. The audit script flags these for review, but only the brand usage is banned.
